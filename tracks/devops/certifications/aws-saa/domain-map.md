# Domain map — AWS Certified Solutions Architect – Associate (SAA-C03)

> Đối chiếu từng task statement trong exam guide (`exam-guide.md`, bản 1.1) với bài học. Mã bài `MM-LL` = module MM, bài LL. Trạng thái: **đã phân bổ** (có bài trong roadmap, chưa viết nội dung) → **đã học** → **đã ôn**.
> Khi viết bài (`/hoc`), mentor đọc danh sách Knowledge/Skills của task tương ứng trong `exam-guide.md` để phủ đủ chi tiết.

**Độ phủ**: 15/15 task statement đã có bài (100%). Đã bổ sung 3 bài (08-08, 08-09, 08-10) để phủ storage nâng cao, mạng hybrid và data ingestion.

**Phần mang tính "học thuộc" ngoài công việc DevOps** (học ở giai đoạn luyện thi): dịch vụ AI (Rekognition, Comprehend...), Neptune, Keyspaces, Snow Family, Application Migration Service — nhận diện use case, không cần thực hành.
